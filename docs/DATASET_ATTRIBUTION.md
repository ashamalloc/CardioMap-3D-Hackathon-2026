# Dataset attribution

**Dataset:** extention of Z-Alizadeh sani dataset

**Creators:** Roohallah Alizadehsani, Mohamad Roshanzamir, Zahra Sani

**Source:** UCI Machine Learning Repository, dataset 411

**DOI:** 10.24432/C5461K

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0)

The UCI repository describes 303 patient records and notes that CAD is present when at least one of the LAD, LCX and RCA arteries is stenotic. The repository also states that LAD, LCX, RCA and Cath should be excluded from classification inputs as appropriate to prevent target leakage.

Project website: https://archive.ics.uci.edu/dataset/411/extention%2Bof%2Bz%2B
